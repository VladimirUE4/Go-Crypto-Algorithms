# **Extreme Encryption Algorithm in Go** 🚀🔐

## **Overview**
This is a **highly secure encryption algorithm** that combines **Argon2 key derivation**, **chaotic transformations**, **AES-256 encryption**, and **HMAC integrity verification**. The algorithm is designed for **maximum security** while remaining **fully decryptable**.

## **How It Works**
### **1️⃣ Key Derivation**
- Uses **Argon2** (resistant to brute-force attacks).
- Introduces **random noise** to make key derivation unpredictable.

### **2️⃣ Chaotic Transformation**
- Inspired by **chaotic systems** (Lorenz, Mandelbrot).
- Each byte is **mathematically transformed** to remove any recognizable pattern.

### **3️⃣ AES-256 Encryption**
- Uses **Cipher Feedback Mode (CFB)** for strong encryption.
- **Fractal-based permutation** makes statistical attacks impossible.

### **4️⃣ HMAC-SHA256 for Integrity**
- Ensures data **has not been modified**.
- Protects against **tampering and replay attacks**.

## **Usage**
### **Encryption**
```go
encrypted := encrypt("Ultra Secure Message!", "supersecurepassword")
fmt.Println("🔐 Encrypted:", encrypted)
```
### **Decryption**
```go
decrypted := decrypt(encrypted, "supersecurepassword")
fmt.Println("🔓 Decrypted:", decrypted)
```

✅ **Brute-force resistant** (Argon2 key derivation).  
✅ **Chaotic transformations prevent pattern recognition**.  
✅ **AES-256 ensures strong encryption**.  
✅ **HMAC prevents tampering and replay attacks**.
